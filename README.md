# 🚀 CVERSE - Profesyonel Kariyer ve Sosyal Paylaşım Platformu

Modern yazılım geliştiricileri ve teknoloji profesyonelleri için geliştirilmiş, yapay zeka destekli kariyer ve sosyal paylaşım platformu.

CVERSE; sosyal ağ özellikleri, gerçek zamanlı mesajlaşma, iş ilanları, CV analizi ve yönetim panelini tek bir platformda birleştirir.

---

## ✨ Özellikler

- 🔐 JWT Authentication & Authorization
- 👤 Gelişmiş Kullanıcı Profilleri
- 📝 Sosyal Medya Akışı (Feed)
- ❤️ Beğeni, Yorum ve Takip Sistemi
- 💬 SignalR ile Gerçek Zamanlı Mesajlaşma
- 🔔 Anlık Bildirimler
- 🔍 Kullanıcı Keşfetme ve Arama
- 💼 İş İlanları ve Başvuru Sistemi
- 🧠 Google Gemini AI ile CV Analizi
- 👨‍💼 Yönetici Paneli
- 🎮 Mini Oyun Alanı
- 🌙 Dark / Light Tema Desteği
- 📱 Responsive Tasarım

---

## 🏗️ Proje Mimarisi

Proje, **Clean Architecture** prensiplerine uygun olarak geliştirilmiştir.

### Backend Katmanları

- **Cverse.Domain** → Entity ve iş modelleri
- **Cverse.Application** → İş kuralları, DTO'lar ve servis arayüzleri
- **Cverse.Persistence** → PostgreSQL ve Entity Framework Core
- **Cverse.Infrastructure** → SignalR, JWT ve Gemini AI servisleri
- **Cverse.API** → REST API ve Swagger

### Frontend

- React (Vite)
- Tailwind CSS v4
- React Router
- Axios
- Context API

- ASP.NET Core 8
- Entity Framework Core
- PostgreSQL
- SignalR
- JWT Authentication
- FluentValidation

### Frontend
- React (Vite)
- Tailwind CSS v4
- React Router
- Axios
- Context API

### Yapay Zeka
- Google Gemini AI

---

## 🚀 Kurulum

### Backend

```bash
cd backend
dotnet restore
dotnet run --project Cverse.API
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
